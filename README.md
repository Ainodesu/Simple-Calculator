# 💫 Simple Calculator on Rust 🦀

## Requirements 💻

- First, you need to install `rust` on your computer, on windows you could use [Official Site](https://rust-lang.org/learn/get-started/).
- That's all 😙

## Instructions 📃

### Windows 🪟

  1. Open `cmd.exe` or `Powershell`
  2. Write: `cargo run [num] [num]`
  3. Done!

### Linux 🐧

  1. Open your Terminal
  2. Write - `cargo run [num] [num]`
  3. Done!
