## Requirements 💻

- First, you need to install `Rust` on your computer, install `Rust` on [Official Site](https://rust-lang.org/learn/get-started/).
- That's all 😙

## Instructions 📃

  1. Open your Terminal
  2. Run `cargo run [number_one] [number_two]` OR `cargo run -- -flag [number_one]`
  3. Enjoy!
