  wanted to make a project!
  This project isn't something special, just project.

## Requirements 💻

- First, you need to install `g++` on your computer, on windows you could use [vcpkg](https://vcpkg.io/en/) or [ucrt64](https://www.msys2.org/)
- That's all 😙

## Instructions 📃

### Windows 🪟

  1. Open `cmd.exe` or `Powershell`
  2. Write(Powershell): `./build.bat`
  3. Next - write(Powershell): `./build/win/cppcalc.exe [number] [number]`
  4. Done!

### Linux 🐧

  1. Open your Terminal
  2. Write - `chmod +x build.sh`, next - `./build.sh`
  3. Next - write: `./build/linux/cppcalc [number] [number]`
  4. Done!
